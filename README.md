# ループ・ミー（Loop Me）

> 10秒ごとに時間が巻き戻る。さっきまでの自分は、今の自分の味方になる。

過去の自分（ゴースト）と協力して解く、1人協力アクションパズルです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド・インストール不要）。

- ループが終わる（時間切れ or `R`）と時間が巻き戻り、さっきの自分の動きが**ゴースト**として再生されます
- ゴーストはスイッチを踏んでくれるし、頭に乗って足場にもできます
- ★を全部集めて（どのループで取ってもOK）ゴールの扉へ
- ゴーストの邪魔をして「記録と違う動き」をさせると、**パラドックス**でゴーストが消えます
- 使ったループ数が少ないほど高評価。目標ループ数でクリアすると「パーフェクト」。クリアタイムも記録されます

## ワールド

| ワールド | ステージ | 登場する仕掛け |
| --- | --- | --- |
| 1 時計塔の夜 | 1-1〜1-10 | スイッチと扉、ゴーストの肩車、動く床、鍵と錠、パラドックス |
| 2 歯車の工場 | 2-1〜2-10 | ジャンプ台、すり抜け床、かけ橋、くずれる床、ゴーストエレベーター |
| 3 時の裂け目 | 3-1〜3-8 | ワープ、時限スイッチ、敵（上から踏むと倒せる） |

各ワールドの最後には**ボス**がいます。ボスも同じループに囚われていて、毎回同じ動きをします。

- 頭を踏むと攻撃できる。ただし**同じ自分の攻撃は1ループに1回しか効かない**
- 攻撃が決まると、ボスは少しの間だけ無敵になる
- つまり、ゴーストと自分で「別々のタイミングに」踏む段取りを組むのが攻略

## そのほかの機能

- **リプレイ**：クリア画面の「リプレイ」で、全員の動きが噛み合う様子を見直せる
- **実績**：タイトルの「実績」から。全15種
- **ヒント**：詰まったらポーズメニューの「ヒントを見る」

## ステージエディタ

ステージ選択の一番下「ステージエディタ」から、自分でステージを作れます。

- パレットからタイルを選んでマップをクリック／ドラッグ（右クリックで消す）
- 名前・制限時間・最大ループ数・目標ループ数・背景を設定
- 「テストプレイ」でその場で遊べる。「保存」でこのブラウザに最大12個まで残せる
- 「共有コードを作る」で `LOOPME1:…` という文字列ができる。友だちはそれを貼って「コードを読み込む」で遊べる

| 操作 | キー |
| --- | --- |
| 移動 | `←` `→`（`A` `D`） |
| ジャンプ | `Space`（`↑` `W`） |
| 巻き戻し（今の動きをゴーストにする） | `R` |
| ひとつ前のループを取り消し | `U` |
| ステージをやり直し | `X` |
| ポーズ（BGM・効果音の設定もここ） / 音のオン・オフ | `Esc` / `M` |

スマホでは画面下のボタンで操作できます（横向きがおすすめ）。

## テスト
